# DEMO SCRIPT: Geolocation & Department Dashboard

## 1. Create a Report (Citizen View)
1. Navigate to **Report Damage**
2. Click **"Get Location"** -> Coordinates will auto-fill from your browser
3. Click **"Open Camera"** -> Take a photo of a pothole (or upload one)
4. Submit the report

## 2. View Department Dashboard (Official View)
1. Log in as an **Official** (or Admin)
2. Click **"Dept. Map"** in the top navigation bar
3. You will see:
   - **Interactive Map**: Markers show report locations
   - **Color Coding**: 
     - 🟠 Pending
     - 🔵 In Progress
     - 🟢 Resolved
   - **Popups**: Click any marker to see the pothole image and details
   - **List View**: Recent reports table below the map

## 3. Verify Data
- Check that the report you just created appears on the map at the correct location
- Verify the image is visible in the popup

---
**Note:** Ensure your browser allows location access and camera access for the demo to work.
